📊 O que faz esta integração?

Sistema completo de integração MikroTik + Google Sheets com automações inteligentes!

🔄 FUNCIONAMENTO BÁSICO:

• Recebe cadastros do hotspot em tempo real

• Registra logs completos (conexão + desconexão + IP)

• Organiza dados em abas separadas (USUARIOS / LOGS)

🤖 AUTOMAÇÕES INTELIGENTES:

• Limpeza de duplicatas: Remove usuários repetidos a cada 4h (mantém o mais recente)

• Backup mensal: Arquiva logs antigos (>30 dias) em abas mensais a cada 12h

• Performance otimizada: Planilha sempre limpa e organizada

📁 ESTRUTURA DAS ABAS:

• USUARIOS: Lista única de clientes cadastrados

• LOGS: Conexões dos últimos 30 dias

• LOGS_2025_01: Janeiro arquivado automaticamente

• LOGS_2025_02: Fevereiro arquivado automaticamente

📋 PLANILHA MODELO PRONTA (Apps Script incluso)

📋 COMO PUBLICAR O APPS SCRIPT (detalhado):

  1. Abrir Apps Script: Na planilha → "Extensões" → "Apps Script"
  2. Publicar: Clique em "Implantar" (canto superior direito)
  3. Nova implantação: Clique em "Nova implantação"
  4. Tipo: Clique no ícone ⚙️ → "Aplicativo da web"
  5. Configurar:
    • Executar como: "Eu" (seu email)
    • Quem tem acesso: "Qualquer pessoa"
  6. Implantar: Clique "Implantar" → Autorizar se necessário
  7. Copiar URL: Copie a URL longa que aparece (termina com /exec)
  8. Ativar automação: Execute a função "configurarTriggers" uma vez
