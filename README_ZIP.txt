🚀 COMEÇAR EM 5 MINUTOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Extrair o ZIP:
   unzip processo-audit-app.zip

2. Entrar na pasta:
   cd processo-audit-app

3. Ler instruções:
   Abra o arquivo START_HERE.md

4. Instalar:
   npm install
   cd frontend && npm install && cd ..

5. Configurar:
   cp .env.example .env
   Edite .env com suas credenciais MySQL

6. Inicializar BD:
   npm run db:init

7. Rodar (2 terminais):
   Terminal 1: npm start
   Terminal 2: cd frontend && npm run dev

8. Acessar:
   http://localhost:3000
